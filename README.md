# Learning Tracker

A minimalist, fully offline study journal that logs daily topics, tracks learning streaks, and organizes revision notes in a clean dark UI.

## Overview

Learning Tracker is a browser-based application designed for students and professionals who want to maintain a structured learning journal without external dependencies. Everything runs entirely in your browser with zero setup, zero tracking, and instant local data backup.

## Features

- Daily topic logging with timestamps
- Learning streak tracking
- Revision notes organization
- Dark UI for comfortable usage
- Completely offline functionality
- Automatic local storage backup
- No external dependencies
- Zero tracking or data collection

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start tracking your learning immediately

## How It Works

The application uses browser localStorage to persist all your data locally. No information is sent to any server. All entries are stored on your device and can be exported for backup.

## Use Cases

- Track daily study sessions
- Maintain learning consistency
- Organize revision materials
- Monitor learning patterns over time
- Build study habits

## Technical Details

- Built with HTML, CSS, and JavaScript
- No framework dependencies
- Single-file deployment
- Cross-browser compatible
